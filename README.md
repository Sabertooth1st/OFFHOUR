# OFFHOUR Volume 01

A fictional premium unisex clothing label and portfolio concept by UZICE STUDIO. Simulated commerce only: nothing is sold, no payment is processed, no email is sent.

## Run

```bash
npm install
npm run dev            # http://localhost:5173
npm run build          # type-check + production build
npm run preview        # http://localhost:4173
npm run verify         # end-to-end checks against the preview (needs Chromium)
```

## Stack

Vite, React 19, TypeScript, React Router (data router), plain CSS with design tokens in `src/styles/tokens.css`, and `motion` only for scroll-bound values (hero depth, editorial parallax, garment study). Fonts are self-hosted OFL faces: Archivo (condensed display) and Hanken Grotesk (interface).

## Where things live

- `src/data/catalogue.ts` is the single typed source for products, colours, sizes, prices, looks, search and sort.
- `src/data/images.ts` + `plates.json` map every picture slot to files in `public/img`.
- `src/state/bag.tsx` is the bag (localStorage with an in-memory fallback, validated against the catalogue on load).
- `src/components/Overlay*.tsx`, `panels/` hold the shared focus-managed overlays (bag, menu, search, info, look, fabric).

## Imagery: placeholder plates

No photography is bundled. Every picture is a labelled **placeholder plate** generated by `scripts/make-plates.mjs` (procedural concrete, plaster and weave textures; garment views show a fabric colour sample, not the garment). Replace any `public/img/<id>-<width>.jpg` with a real photograph of the same id and aspect ratio, or run:

```bash
XAI_API_KEY=... node scripts/generate-grok.mjs   # untested, see the header of the script
```

## Demo disclosures

The footer, bag, product page, newsletter form and info dialogs all state that this is a concept store. "Continue demo" ends in an explanation, never an order confirmation.
